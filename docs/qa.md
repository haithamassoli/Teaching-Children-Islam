# سجل التحقق

البيئة: Chromium محلي، Next.js 16.3.4، Convex development للمشروع `teaching-children-islam`. هذه نتائج فحوص تقنية، وليست اعتماد محتوى أو تجربة أطفال.

| الفحص | النتيجة |
|---|---|
| TypeScript وBiome وبناء الإنتاج | ناجح |
| اختبارات Vitest | ٢١ اختبارًا ناجحًا |
| فصل الأسر وملفات الأطفال وصلاحيات الوالد | ناجح في اختبارات الخادم ورحلة متصفح بحسابين اصطناعيين |
| إنشاء طفلين واختيار الشخصية وقفل الوالد عند بدء الرحلة | ناجح في المتصفح |
| استعادة PIN بكلمة المرور من الشاشة المقفلة | ناجح في المتصفح |
| مكافآت غير متكررة، ترتيب إكمال الدرس/النشاط، المحاولة الأولى | ناجح بعينات تقنية داخل اختبارات الخادم |
| حفظ واستبدال WAV، إثبات المدة من الملف، منع تنزيل أسرة أخرى | ناجح في اختبارات HTTP وConvex Storage |
| رفض الميكروفون وسحب الموافقة وفشل الرفع وإعادة المحاولة | ناجح في متصفح مع محاكاة الحالات |
| التسجيل والترميز والتشغيل الفعلي | ناجح باستخدام MediaRecorder وميكروفون Chromium الاصطناعي |
| الاختيار والترتيب والمطابقة والتصحيح وإعادة المحاولة | ناجح في صفحات QA المحلية، دون مادة تعليمية غير معتمدة |
| إتاحة شاشة الحساب بعرض ٣٩٠ بكسل | صفر مخالفات axe وصفر تجاوز أفقي |
| اتصال بطيء | نجح تحميل شاشة الحساب على الجوال مع تأخير ١٥٠ مللي ثانية وتنزيل ٩٦ كيلوبايت/ثانية |
| انقطاع الاتصال ثم عودته | ظهرت رسالة الانقطاع ثم زالت عند الاتصال |
| manifest والأيقونات وقابلية تثبيت Chromium | ناجح؛ لا أخطاء installability من بروتوكول المتصفح |
| منع صفحات QA وأصول المسودة في الإنتاج | ناجح: HTTP 404 |
| جرد المحتوى والأصول | ٢٥٤ صفحة، ١١١ درسًا، ١٣٠ عنصر حفظ، ١١٠ أصول؛ فحوص السلامة ناجحة |
| بوابة الإطلاق الكامل | ترفض الإصدار الحالي عمدًا لغياب أدلة الاعتماد والأصول النهائية |

حُذفت حسابات الاختبار الاصطناعية وملفاتها. حذف الحساب والطفل يمنع الوصول فورًا ثم ينفذ تنظيف البيانات والملفات على دفعات؛ اختبار الخادم يتحقق من اكتمال الدفعات.

## إعادة الفحوص

```sh
npm test
npm run lint
npm run typecheck
npm run test:content
python3 scripts/check_assets.py
npm run build
# شغّل npm start -- --port 3001 في طرفية أخرى:
node scripts/smoke.mjs http://localhost:3001
node scripts/check-pwa.mjs http://localhost:3001
```

لاختبارات المتصفح المحلية، شغّل `CONTENT_PREVIEW=true npm run dev` مع CLI ‏`agent-browser` المثبت:

```sh
node scripts/check-activities.mjs
node scripts/check-recorder.mjs
node scripts/check-native-recording.mjs
node scripts/check-family.mjs
```

الأمر الأخير يستخدم بيئة Convex المهيأة وينشئ حسابين اصطناعيين ثم يحذفهما. إن فشل التنظيف، يحفظ بيانات الاستعادة في `/tmp/check-family-recovery.json` بصلاحية `0600`؛ أعد التنظيف باستخدام `FAMILY_RECOVERY_FILE=/tmp/check-family-recovery.json node scripts/check-family.mjs` دون طباعة الملف.

## ما لم يثبت بعد

لم تُجرَ تجربة أطفال أو اختبارات هواتف iOS/Android فعلية أو اختبار تثبيت من الشاشة الرئيسية. لم يُنشر موقع إنتاج أو يُنفذ تمرين استعادة نسخة احتياطية في بيئة إنتاج. المحتوى ما زال مسودة؛ لا تثبت عينات QA صحة النصوص الدينية أو ملاءمتها للعمر أو وجود التلاوات النهائية. تعطيل التحقق والاستعادة بالبريد قرار صريح من صاحب المشروع في هذه المرحلة.
