# جزر العجائب

مجموعة إضافية بطابع خيالي غير واقعي. تُعرض داخل التطبيق في `/fantasy`، مع مدخل من الصفحة الرئيسية، وفي [مكتبة الأصول](../index.html#fantasy-characters). بقيت جميع الصور القديمة ومساراتها كما هي.

| الفئة | العدد | المسار |
|---|---:|---|
| وميض، غيمة، برعوم، قطرة | ٤ شخصيات غير بشرية | `characters/`؛ PNG أصلي شفاف وWebP للعرض |
| جزر عائمة مرتبطة بالعوالم السبعة | ٧ SVG | `worlds/` |
| شارات مكتسبة ومقفلة | ١٤ SVG | `badges/` |
| نجوم، حالات ٠–٣، كأس وزينة احتفال | ٨ SVG | `rewards/` |
| الاختيار والمطابقة والترتيب والحكاية | ٤ SVG | `activities/` |
| فانوس، بوصلة، مفتاح وصندوق | ٤ SVG | `objects/` |

الشخصيات مولّدة بأداة **imagegen المدمجة**؛ النصوص الكاملة محفوظة في [image-prompts.json](image-prompts.json). احتُفظ بالأصول وشفافيتها، واستخدم `cwebp -q 86 -resize 640 640` لنسخ العرض. تخضع المخرجات لشروط حساب أداة التوليد؛ لا تدّعي المجموعة حقوقًا حصرية.

رسومات SVG أصلية مرسومة بالكود، وتعيد استخدام رموز المشروع الحالية داخل الشارات. مصدرها القابل للتعديل [build_fantasy_assets.py](../../scripts/build_fantasy_assets.py). لا تحتوي على خطوط خارجية أو JavaScript أو صور مرتبطة. المعرّفات والأسماء والربط بالدروس في [catalog.json](catalog.json)، والتسجيل في [الفهرس الرئيسي](../manifest.json).

صفحة المجموعة تعرض الرسومات وتعرّف بالشخصيات، وتصل الجزر بدروس عوالمها الحالية. النجوم والشارات فيها معاينة بصرية؛ لا تمنح تقدمًا أو مكافآت للحساب. الأدوات عناصر قصصية، وليست متجرًا أو عملة. الجزر أماكن خيالية للواجهة ولا تصوّر أحداث النصوص الدينية.

رُوجعت الرسومات بصريًا بواسطة Codex لإضافتها بناءً على طلب المستخدم، وسُجّل ذلك باسم `codex_visual_review`؛ ليست مراجعة منسوبة إلى صاحب المشروع أو اعتمادًا لمحتوى تعليمي جديد.

من جذر المشروع:

```sh
python3 scripts/build_assets.py
python3 scripts/check_assets.py
```

البناء يحافظ على حالة مراجعة أي ملف لم تتغير بصمته، ويعيد الرسومات المتغيّرة للمراجعة. سكربت المجموعة لا يكتب خارج `assets/fantasy/`، ولا يعيد توليد الشخصيات.
