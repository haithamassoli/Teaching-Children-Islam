# رِحلة الإسلام — تعليم الأطفال الإسلام

موقع عربي RTL للأطفال من ٦ إلى ١٠ سنوات، مبني بـNext.js وConvex Auth. يضم الكتاب كاملًا بصفحاته الـ٢٥٤ بلا تلخيص، و٧ عوالم مصوّرة، و١١١ درسًا و٢٢٧ سؤالًا، ومكتبة للأذكار والحفظ وأنشطة الكتاب. حساب الأسرة يحفظ ملفات الأطفال والتقدّم والنجوم والتسميع ومراجعة الوالد.

## التشغيل

```sh
npm ci
npx convex dev --once
npm run dev
```

استخدم إعداد Convex الحالي في `.env.local`. الصفحة الرئيسية والمكتبة والدروس تعمل دون تسجيل دخول. حساب الأسرة على `/family` يتطلب `NEXT_PUBLIC_CONVEX_URL`. تسجيل الدخول بالبريد وكلمة المرور دون خدمة بريد، وفق قرار صاحب المشروع؛ يمكن استعادة PIN بكلمة مرور الحساب.

## المحتوى والأصول

أكد صاحب المشروع مراجعة كل المحتوى واعتماده في ٨ سبتمبر ٢٠٢٦؛ سُجّل التأكيد في ملفات JSON. يقرأ الموقع والخادم الكتالوج نفسه من `lib/catalog.ts` ويستبعدان أي مسودات مستقبلية. تعرض الدروس صفحات الكتاب الأصلية كاملة داخل الموقع بدل المقاطع المختصرة، وتعرض القصص نصوصها الكاملة مع صفحاتها. ويتيح `/book` تصفح الصفحات الـ٢٥٤ كلها دون فتح ملف PDF خارجي.

الصور والشخصيات والشارات والمؤثرات الأصلية تُقدّم عبر مسار الأصول المعتمد. أصوات المرشد الاصطناعية تبقى غير منشورة حتى توثيق حقوقها، والتلاوات غير المنتجة لا تظهر كمشغّل فارغ. الحركات تستخدم CSS وتراعي تقليل الحركة، مع زر لإيقافها ومؤثرات اختيارية مكتومة افتراضيًا.

التدريب العام لا يحفظ إجابات أو يمنح نجوم حساب. في حساب الأسرة تُصحّح الأنشطة المنظمة على الخادم، وتُناقش الإجابات المفتوحة مع الوالد. الدرس المفتوح يتيح الانتقال بعد القراءة، دون منح نجوم نشاط تلقائية.

القراءة العربية تعمل تلقائيًا للنصوص الكاملة المحررة للقصص الـ٢٣، والأسئلة وخياراتها وتعليقات الإجابة، وبطاقات المكتبة عند فتحها. صفحات الكتاب الأصلية معروضة كصور دقيقة للحفاظ على الآيات والرسوم والجداول، وتحت كل صفحة نصها المستخرج القابل للقراءة. زر «استمع» يعيد المقطع، والشريط السفلي يتيح الإيقاف وتغيير السرعة ويحفظ التفضيل على الجهاز. قد يحتاج المتصفح ضغطة أولى للسماح بالصوت. تستخدم القراءة `speechSynthesis` وصوتًا عربيًا متاحًا على الجهاز، وتعرض رسالة عند غيابه؛ جودة الصوت والعمل دون اتصال يعتمدان على الجهاز ومزوّد الصوت. يتوقف السرد عند مغادرة المقطع أو بدء تسجيل أو تشغيل ملف صوتي. قراءة تعليمات الحفظ منفصلة عن التلاوة، ولا تُنشئ تلاوة قرآنية بديلة.

## التحقق والإصدار

```sh
npm run lint
npm run typecheck
npm test
npm run test:content
python3 scripts/check_assets.py
npm run build:release
# مع تشغيل الموقع وتوفر agent-browser:
node scripts/check-journey.mjs
npm run test:narration
```

`build:release` يتحقق من النسخة النصية المعتمدة ويبني ١١١ صفحة درس. لفحص اكتمال النسخة الصوتية المصوّرة مستقبلًا: `python3 scripts/build_content.py --require-media`؛ يظل هذا الفحص يفشل إلى أن تتوافر وسائط الدروس والتلاوات المطلوبة.
