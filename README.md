# تعليم الأطفال الإسلام

تطبيق عربي RTL للأطفال من ٦ إلى ١٠ سنوات، مبني بـNext.js وConvex Auth. يشمل حساب الأسرة وملفات الأطفال وPIN الوالد ومسار الدروس والنجوم والحفظ والتطبيق والمراجعة الخاصة.

## التشغيل

```sh
npm ci
npx convex dev --once
# عند إعداد مشروع جديد: npx @convex-dev/auth
npm run dev
```

استخدم إعداد Convex الحالي في `.env.local`. تسجيل الدخول بالبريد وكلمة المرور دون خدمة بريد، حسب قرار صاحب المشروع؛ لا تُرسل رسائل تحقق ولا تتاح الاستعادة البريدية. يمكن استعادة PIN بكلمة مرور الحساب.

للنموذج المحلي فقط: `CONTENT_PREVIEW=true npm run dev`. النموذج وصفحات QA لا تتاح في الإنتاج. حسابات الأسرة الحقيقية متاحة محليًا على `/family` حتى عند فتح النموذج.

## الاختبارات والإصدار

```sh
npm run typecheck
npm run lint
npm test
npm run test:content
npm run build
```

فحوص المتصفح والميكروفون وقابلية التثبيت في [سجل التحقق](docs/qa.md). تعليمات النشر والتراجع والنسخ الاحتياطي في [دليل التشغيل](docs/operations.md).

**المشروع ليس إطلاقًا تعليميًا كاملًا بعد.** المواد الـ١١١ وعناصر الحفظ الـ١٣٠ ما تزال مسودات تحتاج اعتماد المختص والنصوص والتلاوات والأصول النهائية. يمنع الخادم عرضها بوصفها دروسًا معتمدة. يشترط الإطلاق الكامل نجاح `npm run build:release` ومهام قبول الأجهزة والأطفال في [tasks.md](tasks.md).
